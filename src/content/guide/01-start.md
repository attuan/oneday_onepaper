# 3 分で始める

このアプリでやることは 1 つだけ。**1 日 1 本、読んで、1 行書く。** API キーも登録も要らない。

## 1. 読むものを入れる

左(スマホでは上)の「論文を探す」を開く。

1. 「入門コースを作る」が選ばれているのを確かめる
2. 「興味のあるキーワード」に、研究室のテーマや気になる言葉を入れる(例: `retrieval augmented generation`)
3. 「探す」を押す
4. 出てきた候補を眺めて、「この 10 本をコースとしてキューに入れる」を押す

全体像が分かるもの → 基礎 → 最近の研究、の順に並んだ 10 本が入る。何から読めばいいか分からなくても、上から読めばよい。

読みたいものが決まっているなら、「論文リスト」の「DOI で追加」に DOI か arXiv ID を貼る。ブログや解説記事は「記事を追加」に URL とタイトルを入れる。

## 2. 今日の 1 本を読む

「ホーム」に今日の 1 本が出ている。「詳細」を押すとアブストラクトとリンクが見える。

時間が無い日は、**アブストラクトと図だけ**でよい。気分が乗らなければ、下の「こっちでも」から別の 1 本を選べる。

## 3. 1 行書く

「メモを書く」を押し、一番上の「ひとこと」の下に、自分の言葉で 1 行書いて「保存」。

20 文字を超えたら**読了**。今日の記録がつき、連続記録が 1 日伸びる。今日はこれで終わりにしてよい。
