# AI を使う

読了すると、メモの画面の右(スマホでは下)に「AI 要約とフィードバック」が出る。**API キーが無くても使える。**

## 返ってくるもの

- **要約**: 問題・手法・結果・限界。各項目の下に、根拠になった原文の引用が付く。アプリが原文と照合していて、見つからない引用には「原文に見つかりません」と出る。そこは自分で確かめる
- **メモへのフィードバック**: よく捉えている点、論文にあってメモにない点、読み違えているかもしれない点、次の一歩。点数は折りたたみの中にある(成績ではなく目安)

アブストラクトだけから作った要約には、その旨が表示される。本文の細かいところまでは入っていない。

## 実行方法は 3 つ

パネルの「実行方法」で選ぶ。キーが無ければ、自動でキーの要らない方法になる。

### 好きな AI に貼り付ける(どの端末でも)

1. 「1. プロンプトをコピー」を押す
2. ChatGPT や Claude などのチャットに貼って送る
3. 返ってきた JSON をまるごとコピーする
4. このアプリに戻って「2. 結果を貼り付ける」を押す

### Apple Intelligence(iPad / iPhone / Mac。キー不要)

iPadOS / iOS / macOS 26 以降で、Apple Intelligence が使える端末の Safari で開いているとき。初回だけ、ショートカット App で次の 3 つのアクションを並べたショートカットを `OneDayOnePaper` という名前で作る。

1. 「クリップボードを取得」
2. 「モデルを使用」— モデルは Private Cloud Compute がおすすめ。プロンプトの欄に 1 の「クリップボード」を入れる
3. 「クリップボードにコピー」— 2 の「応答」を入れる

使うときは「1. Apple Intelligence で実行」を押す。ショートカットが動いて、終わるとこのページに戻ってくる。戻ったら「2. 結果を貼り付ける」を押す。

### API(キーがある人)

設定の「LLM」で選ぶ。

- Anthropic API
- OpenAI 互換: OpenAI、Google Gemini(無料枠がある)、OpenRouter、Groq、LM Studio など。接続先を選び、モデル名とキーを入れる
- Ollama(手元で動かしている人)

API があると、論文を探すときの順位付けと「読むべき理由」、全文 PDF を渡した要約、月のまとめの下書きもその場で動く。全文を渡すときは、実行の前にだいたいの金額が出る。

## 論文の何を AI に渡すか

「LLM に渡す論文情報」で選ぶ。既定はアブストラクトのみ。PDF が取れている論文は全文も選べる。記事や、PDF が取れない論文は「本文を貼り付ける」を使う。
