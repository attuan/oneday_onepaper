# データと詳しい機能

## データはどこにあるか

- **ブラウザ版**: そのブラウザの中。**サイトデータを消すと消える。** 端末やブラウザが違えば別のデータになる
- **デスクトップ版**: `書類/OneDayOnePaper` フォルダ。メモは 1 本ずつ Markdown のファイルなので、ほかのアプリでも開ける

## バックアップと引っ越し

設定の「データ」で、

- 「書き出す」: メモ・論文リスト・記録が 1 つの ZIP になる。ブラウザ版は月に 1 回くらい書き出しておく
- 「取り込む」: ZIP を選ぶと、今のデータと置き換わる(置き換える前の状態は自動で残る)

API キーや Webhook の URL は ZIP に入らない。引っ越し先で入れ直す。

## 詳しい機能を出す

最初は、選ぶものを増やさないために隠してある。設定の一番上の「詳しい設定と機能を出す」にチェックを入れると出る。

- BibTeX の取り込み・書き出し(Zotero などと行き来する)、CSV の取り込み
- 論文を探すときの検索ソースの選択(OpenAlex、Semantic Scholar、arXiv、PubMed、CiNii、J-STAGE など)
- arXiv の手元の索引(デスクトップ版だけ。下の「arXiv の手元の索引」)
- API の使用量と概算の金額
- ポモドーロタイマー
- 日付の切り替え時刻(既定は朝 4 時。深夜に読んだ分が「今日」に入る)、猶予

## arXiv の手元の索引(デスクトップ版)

arXiv 全体のスナップショット(Hugging Face の secemp9/arxiv-complete)から、自分の分野のカテゴリだけを手元に入れておける。

- 設定の「arXiv の手元の索引」でカテゴリ(例: `cs.CL, cs.LG`)を入れて「取得して索引を作る」。最初に約 1.6 GB を取得するので、Wi-Fi で数分待つ
- できると、「論文を探す」のソースに「arXiv(手元の索引)」が出る。ネット無しで引けて、混んでいて失敗することがない
- カレンダーの月のまとめに「近いが未読の論文」が出る。読んだもののタイトルの語で同じ頃の論文を引いたもの。そのままキューに入れられる。「関連研究」の下書きでは「まだ読んでいなさそうな観点」の材料になる
- 収録はスナップショットの日付まで。それより新しいものは普通の arXiv 検索で

## 困ったとき

- **AI の結果を貼り付けても読み込めない**: AI の回答の JSON を、最初の `{` から最後の `}` までまるごとコピーする。だめなら「うまくいかないとき」を開いて、欄に直接貼る
- **ショートカットが開かない**: ショートカットの名前が、設定の「ショートカットの名前」と同じか確かめる
- **PDF が取れない**: 有料の論文は取れない。リンクから開いて読み、AI には「本文を貼り付ける」で渡す
- **論文を探すと失敗が出る**: 検索先が混んでいることがある。少し待ってもう一度
