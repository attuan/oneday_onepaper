# 研究室で使う

読了したら、研究室の Slack に自動で投稿できる。

```
📖 attuan が今日の 1 本を読みました(連続 3 日)
Attention Is All You Need(Vaswani ほか, 2017)
> RNN を使わず注意機構だけで翻訳の精度を上げた論文
https://doi.org/...
```

投稿されるのは、タイトル・連続記録・**メモの最初の 1 行だけ**。メモの全文は送られない。

人に見られていると続く。同じ研究室の人が何を読んでいるかも分かる。

## 設定のしかた

1. Slack の「アプリ」から「Incoming Webhooks」を追加し、投稿先のチャンネルを選ぶ。`https://hooks.slack.com/services/...` という URL が発行される
2. このアプリの設定の「読了を Slack に共有」に、その URL と、投稿に出す名前を入れる
3. 「読了したら自動で投稿する」にチェックを入れて「保存」
4. 「テスト投稿」で届くか確かめる

通知(「まだ読んでいません」など)の送り先とは別なので、研究室のチャンネルに催促が流れることはない。

投稿に失敗したときや、ひとことを書き直したあとは、メモの画面の「Slack にもう一度投稿」で送り直せる。
